# Portal Concursos PWA

MVP inicial de um portal de preparação para concursos.

## Recursos incluídos
- Dashboard
- Cronograma
- Mini simulado em modo prova
- Cartão de respostas
- Resultado final
- Flashcards
- Caderneta de erros (estrutura inicial)
- Manifesto PWA

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000
